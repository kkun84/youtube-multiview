# youtube-multiview

YouTubeの動画や配信を1画面に並べて、同時に再生するページです。iPadやiPhoneのホーム画面に追加して、アプリのように使うことを想定しています。

https://kkun84.github.io/youtube-multiview/

## 使い方

- **動画を選ぶ:** 左上の「動画の追加・削除」から、YouTubeの動画や配信のURLを1つずつ追加します。1〜9個まで並べられ、一覧の「削除」で外せます。
- **音声を選ぶ:** 映像は全部同時に流れます。動画を1回タップすると出るスピーカーのボタンで、その動画の音だけを出せます。音を出している動画は、オレンジの枠で囲まれます。
- **止める:** 動画を1回タップすると出る一時停止ボタンで、その動画だけを止められます。上の帯の一時停止ボタンは、全部をまとめて止めたり再生したりします。止めた動画は暗くなり、「一時停止中」と表示されます。
- **大きく見る:** 動画をダブルタップすると、その動画を大きく表示し、残りを小さく並べます。もう一度ダブルタップすると元に戻ります。
- **並べ替える:** 動画を1回タップすると出る移動ボタン(点が6つのボタン)をタップし、移動先の動画をタップします。移動ボタンをそのままドラッグしても並べ替えられます。「動画の追加・削除」の一覧でも、上へ・下へのボタンかドラッグで並べ替えられます。一覧の上から順に、画面の左上から右下へ並びます。
- **並び方を変える:** 上の「自動・1列・2列…・大きく」で変えられます。「自動」は、画面の縦横サイズから動画が一番大きく映る列数を選びます(iPhoneの縦なら1列、iPadの横なら2×2)。

並べた動画は、端末の中とURLの`#v=`以降に保存されます。そのURLを開けば、同じ並びで見られます。

## ライブ配信向けの機能

- **遅れの表示:** 一時停止などでライブより20秒以上遅れた配信には、左上に「ライブに戻る(◯分遅れ)」が出ます。押すと最新の位置に飛びます。上の帯の電波のボタンで、遅れている配信をまとめてライブに合わせられます。
- **ライブチャット:** 上の帯の吹き出しのボタンで、選んだ配信のチャットを横(縦長の画面では下)に表示します。YouTubeの仕様で、スマホのブラウザでは埋め込みのチャットが出ないことがあります。そのときは「YouTubeで開く」から見てください。
- **配信の終了:** 配信が終わったり再生できなくなったりした動画には、その旨と「一覧から外す」ボタンを表示します。

## ホーム画面に追加する

Safariの共有ボタンから「ホーム画面に追加」を選ぶと、アドレスバーのない全画面で使えます。ホーム画面から開いたときと、Safariで開いたときとでは、並べた動画の保存先が別になります。

## 音声が1つだけの理由

iOSとiPadOSのSafariでは、音声付きで再生できる動画は同時に1本だけです。ホーム画面に追加しても同じです。ミュートした動画は同時に再生できるので、このページは音声を出す動画を1つに絞り、残りはミュートして再生を続けます。Safariが無音の動画を止めたときは、3秒以内に再生し直します。

## YouTubeの操作パネル

既定では、動画のタップで一時停止したり、ダブルタップで10秒移動したりしないように、YouTubeの操作パネルを隠しています。画質を変えたいときは、「動画の追加・削除」の中の「YouTubeの操作パネルを使う」をオンにします。

## 使っているもの

- [YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference)
- [UI SDK](https://ui-sdk.dev)(Vercel Labs、ベータ版): ダイアログ、ツールバー、並び方の切り替え、入力欄などの部品と、並べ替えの動き(`createReorder`)

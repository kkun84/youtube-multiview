# youtube-multiview

YouTubeの動画や配信を、1画面に並べて同時に再生するページです。iPadで複数の配信を見ることを想定しています。

https://kkun84.github.io/youtube-multiview/

## 使い方

1. 「URLを編集」に、見たい動画や配信のURLを1行に1つずつ入れます(最大9つ)。
2. 全部の映像が無音で同時に再生されます。
3. 各画面の「この音声」を押すと、その動画の音だけが出ます。ほかの映像は止まりません。

表示中の動画はURLの`#v=`以降に入るので、そのURLを開けば同じ並びで見られます。

並び方は、画面の縦横サイズから動画が一番大きく映る列数を自動で選びます(iPhoneの縦なら1列、iPadの横なら2×2)。「並び」ボタンで列数を固定することもできます。選べるのは、段の数が変わる列数だけです(4つなら1列・2列・4列)。

## 音声が1つだけの理由

iOSとiPadOSのSafariでは、音声付きで再生できる動画は同時に1本だけです。ミュートした動画は同時に再生できるので、このページは音声を出す動画を1つに絞り、残りはミュートして再生を続けます。
